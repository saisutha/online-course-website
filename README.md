# Online Course Website - EduSphere Academy (Group 2)

An online learning platform featuring course categories, course cards with star ratings & instructor avatars, faculty profiles, student reviews, and enrollment options.

## Project Overview
- **Technology Stack**: 100% Pure HTML5 and CSS3 (Zero JavaScript)
- **Design Philosophy**: Semantic, fully responsive (desktop, tablet, mobile), modern typography, and clean layout structure.

## File Structure
- index.html: Semantic webpage structure and content.
- style.css: Comprehensive responsive styles, CSS variables, and modern visual design.

## How to Run Locally
1. Clone the repository:
   ``bash
   git clone https://github.com/saisutha/online-course-website.git
   ``
2. Open index.html in any web browser.
